# AGENTS.md

Guidance for AI agents (and humans) working on **the-gang-online**, a fan-made, unofficial online adaptation of the cooperative card game *The Gang* (John Cooper & Kory Heath, published by KOSMOS). It is for personal use by a small group of friends. See `README.md`.

## Stack

- **Next.js 16** (App Router, Turbopack) + **React 19**, TypeScript.
- **Convex** for all game state and realtime sync (`convex/`). There is no other database.
- **Tailwind v4** is installed, but most game styling is hand-written CSS in `app/globals.css` using semantic class names (`.game-shell`, `.heist-score`, `.token-stolen-toast`, …). Follow that existing approach rather than rewriting components in utility classes.
- Icons: `lucide-react`. No emoji icons.
- Package manager: **pnpm** (`pnpm install`, `pnpm dev`).

## Game rules as implemented

All rules live server-side in `convex/rooms.ts`; the client only renders and sends intents.

- **Players:** 2–6 (best with 3–6). Host creates a room (4-character code), others join by code or `?room=CODE` invite link. Host starts once everyone is ready.
- **Rounds per heist:** private cards are dealt (2, or 3 with challenge 10), then four ranking rounds — pre-flop, flop, turn, river — using token colors white → yellow → orange → red. Players pick a token `1..N`; taking a token already held by someone **steals** it (the victim gets a toast).
- **Showdown:** hands are revealed in red-token order, lowest first. A strictly weaker hand than the previous one trips the alarm; **equal hands may come in either order**. On failure, all remaining hands are revealed immediately.
- **Modes:** `advanced` (default), `professional`, `master-thief`.
  - Advanced: success → draw a challenge for the next heist; failure → draw a specialist.
  - Professional: one permanent challenge plus the one drawn after a success; specialists after failures.
  - Master thief: two challenges from the start; each alarm replaces the lowest-numbered active challenge; no specialists. Alarm limit is **2** (otherwise **3**).
- **Challenges (1–10):** Accès rapide (flop before first ranking; excluded outside advanced), Capteurs sonores, Détecteur de mouvement, Scanner rétinien, Fuite précipitée, Conduit d’aération, Rayons laser, Panne de courant, Scanner d’empreintes, Caméras de surveillance. Implemented effects include locked tokens (2 / 6), forced redraws on the flop (3 / 7), turn+river together (5), removing previous-round tokens (8), extra private card (10), and pre-showdown guessing checks on the top red token holder (4: a card value, 9: the hand category).
- **Specialists (1–10):** Informateur, Chauffeur, Investisseur, Cerveau, Hacker, Coordinateur, Valet, Matheux, Escroc, Gros bras. The **Chauffeur (Getaway Driver, #2)** is implemented via `revealHandRanking`.
- **End of game:** currently the game is set to `finished` only when the alarm limit is reached. The host can then `restartGame` back to the lobby.

When changing rules, keep the server as the single source of truth and update the game log events accordingly.

## Hard rule: never leak private cards

This is the most important invariant of the project.

- `getRoom` strips every other player's `cards` until that player's hand is officially revealed. Never return private cards from any other query.
- Game log events, toasts, notices, replays and any shared UI must **never** disclose a player's private cards or hand details before the official reveal — including redrawn cards (challenges 3/7), high-card values, or kickers.
- Allowed public info: token moves/steals, board cards, revealed hands, challenge guesses and their correctness, and the **bare hand category** from the Getaway Driver (`currentHandCategory` deliberately omits high card/kickers).
- When adding a new event type or detail field, check what it exposes in both the live log and the public `/replay/[key]` page.

## Conventions

- **UI language is French.** All user-facing strings (buttons, errors thrown by Convex mutations, log notes) are in French, using typographic apostrophes (`’`). Code, identifiers and comments are in English.
- Keep `layout.tsx` as `lang="fr"`.
- Player identity is a random UUID in `sessionStorage` (`gang-player-id`, `gang-player-name`) — there is no auth by design. The card theme preference uses `localStorage` (`gang-card-theme`); that is the only intended client storage.
- Use Convex `useQuery` / `useMutation` for data; do not fetch in `useEffect`.
- Validate every mutation argument with `convex/values` validators and check room membership / host role server-side.
- Visual direction: warm green felt casino table, chips and playing cards. Toasts sit bottom-right; the heist score must not overlap table buttons; face-card art must stay clear of corner indexes.
- Keep the footer credit stating this is an unofficial adaptation not affiliated with or endorsed by the authors or publisher.
- Accessibility: keep `aria-label`s on icon-only buttons, `role="status"`/`"alert"` on toasts, and handle IME composition on Enter-to-submit inputs (`isComposing` / `keyCode 229`).

## Environment

- `NEXT_PUBLIC_CONVEX_URL` — Convex deployment URL (must be `https://`). Without it the app shows a setup message instead of the game.
- `CONVEX_DEPLOY_KEY` — used to deploy Convex functions.
- Never commit secrets; `.env*` is git-ignored.

## Workflow

- Run locally with `pnpm dev`. After changing anything in `convex/`, deploy the functions (e.g. `npx convex deploy`) so the schema and mutations match the client, and keep `convex/_generated/` in sync.
- Work on a feature branch (`v0/<topic>`) and open a PR into `main`; don't push directly to `main` (it deploys to Vercel).
- `next.config.mjs` has `typescript.ignoreBuildErrors: true`; still keep the code type-correct.
